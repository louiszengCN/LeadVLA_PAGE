# LeadVLA project page

Project website for **LeadVLA: Learning Follower-Aware Route Execution for Robot Leading**.

- Website: https://louiszengCN.github.io/LeadVLA_PAGE/
- Code repository: https://github.com/louiszengCN/LeadVLA_CODE

This repository contains the static website and its presentation media.

## Local preview

From the repository root:

```bash
python3 -m http.server 8766 --bind 127.0.0.1
```

Open http://127.0.0.1:8766/ in a browser. No build step is required.

## GitHub Pages

Publish the repository root from the `main` branch in Settings → Pages.
The `.nojekyll` file enables direct serving of the static files.
